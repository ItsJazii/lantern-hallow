# New models to make the garden come alive

Workflow for each: in Tripo, open **Image**, paste the prompt, generate the picture, check it shows **one** subject, then make the 3D model and texture it. You don't need to rig anything; I rig and animate. Export GLB and drop it into `D:\tripo mini game\models_raw\src\` using the file name in the table (not into `game\`).

Every prompt starts with the same style block so new models match your existing ones. Copy the **style block + the subject line**.
